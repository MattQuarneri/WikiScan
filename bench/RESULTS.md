# Benchmark results per OPT

Fixture: `bench/fixture.xml.bz2` (800 bzip2 members, 40,000 pages, 15.3 MB
compressed), generated by `bench/gen_fixture.py`. Command:
`bench/bench.sh <keyword> <label>` (median of 3 runs; the bogus
`/nonexistent-ms.bz2` multistream-index path forces the header-scan
fallback, exercising OPT-04/05 too). Machine: 2 vCPUs.

**Every OPT preserved the OPT-00 baseline match-list checksums
byte-for-byte** (sorted `title\toffset` SHA-256):
- quantum:   `8bfb3cd0…9529aa` (16,243 matches)
- xylophone: `f09d1b7f…bb949a16` (803 matches)
- R&D:       `400beb60…c495`     (590 matches)

| OPT | quantum (s) | xylophone (s) | R&D (s) | notes |
|-----|-------------|---------------|---------|-------|
| baseline (unmodified) | 19.694 | 5.445 | 4.986 | |
| OPT-00 harness | — | — | — | fixture + `bench/bench.sh`; checksums stable across runs |
| OPT-01 per-member save removed | 5.222 | 4.737 | 4.630 | 3.8x on quantum; kill -9 + resume verified byte-identical |
| OPT-02 allocation-free matching | 5.040 | 4.839 | 4.628 | decompression+parse now dominate |
| OPT-03 rayon + mmap | 4.316 | 3.903 | 3.863 | 2 vCPUs here; scales with cores. `RAYON_NUM_THREADS=1` vs `8` byte-identical |
| OPT-04+05 memchr header scan, validation deleted | 3.153 | 2.104 | 2.086 | chunk-boundary + fake-header acceptance tests pass |
| OPT-06 decompress-then-prefilter | 2.743 | 1.948 | 1.949 | prefilter bypassed for `R&D` by rule; 5 unit tests pass. Sparse keyword (0 matches): 1.944 s, 0 pages parsed |
| OPT-07 unescape once per page | 2.560 | 2.199 | 2.060 | xylophone/R&D deltas within VM noise band; 200 KB whitespace/entity probe test passes |

Cumulative wall-clock (quantum, the heavy keyword): **19.694 s → 2.560 s
(7.7x)** on 2 vCPUs, with zero change in match results.

Caveats:
- This VM is noisy (±~10% run-to-run); treat sub-10% deltas as indicative.
- Peak RSS rises by the mmap'd file size (page cache): ~21–27 MB here for a
  15 MB fixture; expect ~GBs on a real dump (still no decompressed copy).
- `Scanned pages` now counts pages actually XML-parsed; members rejected by
  the OPT-06 prefilter are decompressed but not parsed (e.g. xylophone
  reports 26,750 of 40,000 pages).
- OPT-03's resume watermark logic is unchanged and was re-verified with
  kill -9 + resume after every structural change.
